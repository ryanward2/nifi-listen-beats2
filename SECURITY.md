# Security policy

## Supported version

The actively maintained line is the current `1.x` release targeting Apache NiFi 2.11.x unless a release note states otherwise.

## Reporting a vulnerability

Please report suspected vulnerabilities privately to the repository owner through an appropriate private GitHub contact/security channel rather than opening a public issue containing exploit details.

Useful reports include:

- affected version/commit,
- attack preconditions,
- protocol frame or configuration needed to reproduce,
- impact,
- minimal reproducer when safe to provide,
- suggested mitigation if known.

Do not include credentials, certificates, production payloads, or other sensitive data in reports.
